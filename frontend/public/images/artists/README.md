# Artist Photos

Place your artist photos in this folder with the following names:

- `binara-yomal.jpg` - Photo of Binara Yomal
- `lasal-manith.jpg` - Photo of Lasal Manith
- `tenura-shanelka.jpg` - Photo of Tenura Shanelka
- `ranithu-kannangara.jpg` - Photo of Ranithu Kannangara

## Image Recommendations:
- **Size:** 300x300 pixels (square format works best)
- **Format:** JPG, PNG, or WebP
- **Quality:** High resolution, professional photos
- **Orientation:** Square or portrait orientation
- **Background:** Clean, professional background preferred

## File Naming:
You can use any of these formats:
- `.jpg` or `.jpeg`
- `.png`
- `.webp`

If you use a different format, update the file extension in `/frontend/src/pages/About.js`
